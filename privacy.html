Privacy policy

Effective date: November 15, 2026

This policy describes Hiroyuki Yoshida's personal rclone mount configuration.

Data access and use

With the account owner's authorization, rclone accesses Google Drive file contents and metadata to perform requested file operations. Full Drive scope permits reading, creating, updating, and deleting files that the authorized account can access.

Storage and retention

OAuth credentials and refresh tokens are stored in the owner's local rclone configuration. Downloads and mount caches may store file contents on the owner's computers. These remain until removed by the owner or the configured cache-cleanup process. Unmounting alone does not necessarily delete cached files or revoke authorization.

Sharing

This personal configuration does not sell Google user data or use it for advertising. Files are transferred between Google Drive and the owner's computers for requested operations. The owner remains responsible for any subsequent sharing or use in other applications. This static information website does not receive Drive credentials or file contents. GitHub Pages hosts the website and may process ordinary web request metadata under GitHub's privacy statement.

Control and deletion

The owner can revoke this application's access in Google Account third-party connections and remove local credentials, cached files, and downloaded copies. Revoking access does not automatically delete existing local copies.

Contact

Contact the maintainer through hiro-yoshida on GitHub. Do not post tokens, client secrets, or private Drive files in public issues.
